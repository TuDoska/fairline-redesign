# Fairline — оновлена вітрина (редизайн)

Живе демо: https://tudoska.github.io/fairline-redesign/

Основа — прототип [ForestKOD/fairline-demo2](https://github.com/ForestKOD/fairline-demo2). У цій версії додано:

- нова шапка: знак «гори + вогник» замість кольорових марок, спокійний пошук з іконкою, телефон і «Передзвоніть мені»;
- іконки кабінету, обраного й кошика з лічильниками;
- вхід і реєстрація (вікно та сторінка `account.html`), кабінет: замовлення, обране, особисті дані;
- сердечко «в обране» на картках і сторінці товару;
- у кошику дані покупця підставляються автоматично, замовлення зберігається в кабінеті.

Акаунти в демо зберігаються лише в браузері (localStorage); у робочому проєкті це кабінет покупця OpenCart.

---


Інтерактивний прототип оновленого інтернет-магазину Fairline за ТЗ від 12.10.2026.
Товари, бренди й ціни в прикладі вигадані; ілюстрації векторні й вбудовані в код.

## Що можна подивитися

| Сторінка | Що демонструє |
| --- | --- |
| `index.html` | Динамічна сезонна добірка (перемикається за датами, лише товари в наявності, закріплені позиції), чисте дерево розділів |
| `catalog.html` | Фільтри за нормалізованими атрибутами: OR усередині групи, AND між групами, лічильники, приховані порожні значення, «Скинути все», висувна панель на мобільному; пошук за артикулом (`?q=`); акції лише з реальними знижками (`?sale=1`) |
| `product.html?id=16` | Розміри як варіанти з окремим залишком, недоступний розмір не додається в кошик, ціна «5 490 ₴», статуси наявності, таблиця характеристик, схожі товари |
| `cart.html` | Кошик з кількістю в межах залишку, підсумок, оформлення: Нова пошта / кур’єр / самовивіз, валідація телефону |
| `info.html` | Доставка і оплата, обмін і повернення, гарантія, контакти з формою, про магазин |
| `account.html` | Вхід і реєстрація, кабінет покупця: замовлення, обране, особисті дані |
| `admin.html` | Панель постачальників: «Синхронізувати зараз», статистика, журнал, «Потребує зіставлення», захист ручних правок |

## Як запустити

Просто відкрийте `index.html` у браузері — сервер і збірка не потрібні.

Або увімкніть GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Структура

```
index.html, catalog.html, product.html, cart.html, info.html, admin.html
assets/style.css   — стилі (мотив туристичного маркування стежок)
assets/data.js     — товари, розділи, категорії, добірки
assets/art.js      — векторні ілюстрації товарів і банер
assets/app.js      — вітрина: картки, фільтри, рекомендації, кошик
assets/account.js  — акаунт, обране, вхід/реєстрація, зворотний дзвінок
assets/admin.js    — панель синхронізації постачальників
```

У робочому проєкті ця логіка переноситься в модулі OpenCart: імпорт постачальників,
рекомендації, фільтри та правки теми.
